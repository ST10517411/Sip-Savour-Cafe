Sip & Savour Café Website

 About the Project

Sip & Savour Café is a website created for a local café based in Rosebank, Johannesburg.

The purpose of the website is to provide customers with information about the café, its menu, special offers, location and contact details.

The website was created as part of a POE project.

 Website Pages

The website contains six main pages:

1. Home
2. About Us
3. Menu
4. Gallery
5. Special Offers
6. Contact Us

 Page Information

 Home

The Home page introduces Sip & Savour Café and provides basic information about the business.

 About Us

The About Us page provides information about the café, including its mission, vision, values and target customers.

 Menu

The Menu page shows the available breakfast, lunch, drinks, desserts and pastries together with their prices.

 Gallery

The Gallery page contains pictures of the café, food and drinks.

 Special Offers

The Special Offers page contains weekly promotions, seasonal desserts and upcoming events.

 Contact Us

The Contact Us page provides the café's address, contact details, opening hours, booking form, contact form and location map.

 Technologies Used

The website was created using:

 How to Open the Website

1. Download or clone the project files.
2. Open the project folder in Visual Studio Code.
3. Make sure all six HTML files are in the same folder.
4. Open `index.html`.
5. Open the file in Google Chrome.
